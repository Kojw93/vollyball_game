# 🏐 배구 서브 & 리시브 게임 (1단계 프로토타입)

위에서 내려다보는 배구 코트에서 서브를 넣고, 상대 리시브 결과를 배구 기록 방식(# + ! - / =)으로 보여주는 웹 게임입니다.

## 플레이하기

- 온라인: GitHub Pages를 켜면 `https://kojw93.github.io/vollyball_game/` 에서 바로 플레이할 수 있어요.
- 내 컴퓨터: `index.html` 파일을 크롬 등 브라우저로 열면 됩니다. (설치할 것 없음)

## 하는 방법

1. 위쪽(상대) 코트를 눌러 서브할 곳을 정해요. 서버의 **정확도**가 높을수록 노란 원이 작아요.
2. **서브 토스** 버튼(또는 스페이스바)을 누르면 흰 링이 줄어들어요.
3. 링이 노란 원과 겹쳐 **초록색**이 될 때 **때리기!** 를 누르세요.
   - 성공: 원 안 어딘가에 공이 떨어져요.
   - 실패: 훨씬 넓은 곳에 떨어져요. 빨리 누르면 길게, 늦게 누르면 짧게 가서 아웃이나 네트가 될 수 있어요.
4. 가장 가까운 상대 선수가 달려가서 리시브하고, 결과가 나와요.

| 기호 | 뜻 |
|---|---|
| # | 완벽 |
| + | 좋음 |
| ! | 보통 |
| - | 나쁨 |
| / | 넘어감 (리시브가 우리 코트로 넘어옴) |
| = | 범실 (서브 에이스) |

## 파일 구성

- `index.html` : 화면 뼈대
- `style.css` : 색, 크기 같은 꾸미기
- `js/rules.js` : **게임 규칙과 밸런스 숫자** (원 크기, 리시브 판정 등). 밸런스를 바꾸려면 여기를 고치세요.
- `js/game.js` : 그림 그리기, 터치 처리, 기본 선수 명단

선수 능력치는 게임 화면 아래 **선수 능력치 바꾸기** 에서도 바꿀 수 있어요.
